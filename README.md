## Пакетная обработка (Д2Б5)

Пакет — группа заявок в буфере от одного источника, которая стала доступна диспетчеру
в момент освобождения любого прибора. Правило двухфазное:

1. **Формирование пакета** — при освобождении прибора среди источников, чьи заявки
   сейчас находятся в буфере, выбирается источник с наименьшим номером (наивысший приоритет).
2. **Удержание пакета** — диспетчер продолжает выбирать заявки только этого источника,
   пока пакет не будет исчерпан. Лишь после этого переключается на следующего
   по приоритету клиента.

## Порядок действий при освобождении прибора

1. Прибор освободился.
2. Проверить буфер.
3. Если буфер пуст → ждать следующего события.
4. Если не пуст → сформировать/продолжить пакет по Д2Б5.
5. Найти свободный прибор по Д2П1.
6. Передать заявку на прибор.

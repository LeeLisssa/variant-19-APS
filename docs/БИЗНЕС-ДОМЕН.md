### 1.1 Поток обращений (ИБ, И31)

Заявки формируют владельцы климатической техники. Число потенциальных
клиентов не ограничено, поэтому поток считается бесконечным (ИБ). Моменты
появления обращений описываются пуассоновским процессом (И31): паузы между
соседними заявками — случайные величины с экспоненциальным распределением.
Каждому клиенту присваивается порядковый номер — он используется для
расстановки приоритетов.

### 1.2 Накопитель заявок (Д1О31)

Очередь организована по кольцевому принципу. При добавлении новой заявки
поиск свободной ячейки начинается не с первого слота, а с того места, где
остановился маркер после предыдущей записи. Такой подход исключает
постоянное смещение элементов очереди и позволяет равномерно задействовать
освободившиеся позиции.

### 1.3 Исполнительные устройства (П32)

Роль обслуживающих приборов выполняют диспетчеры. Один диспетчер
одновременно ведёт только одно обращение: проверяет корректность данных,
созванивается с клиентом и формирует задание для выездной группы.
Длительность обработки одной заявки — случайная величина, подчинённая
равномерному закону (П32) на заданном отрезке. Количество диспетчеров
задаётся как отдельный параметр системы.

### 1.4 Правило отказа (Д1ОО1)

Когда кольцевая очередь заполнена и поступает новое обращение, включается
механизм отказа Д1ОО1. Новая заявка не отправляется в конец очереди и не
отклоняется сразу — вместо этого система удаляет заявку, на которую в
текущий момент указывает маркер. Удалённая заявка считается отклонённой,
а на её позицию записывается только что поступившее обращение.
Обслуживание заявок, уже находящихся у диспетчеров, при этом не прерывается.

### 1.5 Алгоритмы распределения (Д2П1, Д2Б5)

**Д2Б5 — пакетный приоритет по источнику.**
Когда диспетчер освобождается и в очереди есть заявки, система сначала
определяет клиента с наивысшим приоритетом среди тех, чьи обращения сейчас
находятся в накопителе. Приоритет задаётся номером источника: чем меньше
номер, тем выше приоритет. Диспетчер получает одну заявку этого клиента.
Если в очереди есть ещё обращения от того же источника, они образуют
пакет, и диспетчер продолжает выбирать заявки только этого клиента, пока
пакет не будет исчерпан. Лишь после этого система переключается на
следующего по приоритету клиента.

**Д2П1 — приоритет приборов по номеру.**
Поиск свободного диспетчера выполняется последовательным перебором,
который всегда начинается с самого приоритетного сотрудника
(Диспетчер №1, затем №2, затем №3 и так далее). Заявка передаётся
первому найденному свободному диспетчеру.

### 1.6 Заявка

Заявка представляет собой одно обращение клиента по поводу неисправности
оборудования. Она содержит номер источника, порядковый номер обращения и
момент поступления. Фиксируются также время начала и окончания обработки —
на их основе вычисляются показатели ожидания, обслуживания и общего
времени нахождения заявки в системе. После завершения обработки заявка
покидает систему.

### 1.7 Представление результатов

В автоматическом режиме (ОР1) формируется сводная таблица по каждому
источнику: число созданных и обработанных заявок, количество и вероятность
отказов, средние значения времени ожидания, обслуживания и пребывания в
системе, а также их дисперсии. По каждому диспетчеру рассчитывается
коэффициент загрузки. В пошаговом режиме (ОД1) выводятся календарь
событий, текущее содержимое очереди и таблица событий системы.
